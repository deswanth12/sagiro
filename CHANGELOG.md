# PaisaPilot Release Changelog

## [2.5.0] - 2027-05-15
### Added
- **Private Sync™ System**: End-to-End Encrypted (E2EE) backup to Google Drive restricted `appDataFolder`.
- **Structured `.ppbackup` Archive (v2.5)**: Manifest UUIDs, HMAC signature, encrypted metadata, and AES-256-GCM encrypted DB export.
- **24-Character Recovery Key**: Bitwarden-style 24-character grouped recovery key generator (`AB9K-T72P-LX8Q-WM4R-ZC1H-K8VP`).
- **Device Migration Wizard**: Sandbox restore simulation preview before atomic database swap.
- **PaisaPilot Trust Center**: Vault audit card displaying 100% on-device guarantees and active security logs.
