# Sagiro Threat Model

| Threat Vector | Mitigation Strategy | Result |
| :--- | :--- | :---: |
| **Lost / Stolen Device** | SQLCipher full-database encryption (AES-256-CBC) on the live `sagiro.db` file. 256-bit key is generated by CSPRNG on first launch and stored exclusively in Android Keystore / iOS Keychain via `flutter_secure_storage`. Plaintext data is never written to disk. | ✅ Protected |
| **Google Account Compromise** | Google receives raw encrypted bytes in `appDataFolder` (AES-256-GCM E2EE backup archives); 0 bytes plaintext ever uploaded. | ✅ Protected |
| **Tampered / Corrupted Backup** | AES-256-GCM Auth Tag + SHA-256 Checksum validation aborts any modified `.ppbackup` payload at restore time. | ✅ Protected |
| **Forgotten Passphrase** | Bitwarden-style 24-character Recovery Key (`REC-XXXX-XXXX` format) generated on first backup, stored in Keychain. | ✅ Protected |
| **IAP Entitlement Spoofing** | Client-side receipt trust (intentional trade-off for serverless model). Server-side Cloud Function receipt validation is planned pre-scale. See `lib/billing/billing_service.dart`. | ⚠️ Accepted Risk |
