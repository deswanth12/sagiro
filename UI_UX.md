## ⚡ Core UX Principles

1. **2-Tap Action Rule**: Reach any major feature or action in 2 taps or fewer.
2. **Actionable Numbers**: Every display number must answer a question (e.g. *"Can I afford dinner tonight? → Today's Safe Spend: ₹425"*).
3. **Privacy First**: Always highlight on-device processing status badges (*"0 Bytes Uploaded"*).
4. **Empty State Philosophy**: Avoid generic "No data" screens. Always prompt: *"Let's build your first month. Add a transaction or import your bank SMS."*
